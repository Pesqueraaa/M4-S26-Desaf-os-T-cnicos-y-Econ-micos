# M4-S26 · Integración IA

## Objetivo
Aplicación web estática para analizar la integración de IA en atención al cliente.

## Funcionalidades
- Introducción de datos
- Cálculos (consultas, tokens, ahorro)
- Matriz comparativa editable
- Mini-RAID editable
- Decisión final
- Resumen copiable

## Uso
1. Introducir datos
2. Pulsar "Calcular"
3. Completar matriz, RAID y decisión
4. Copiar resumen

## Publicación
GitHub Pages (Settings → Pages → main)

## Advertencia
No usar datos personales reales.
